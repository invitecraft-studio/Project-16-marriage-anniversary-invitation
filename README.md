# One year, a thousand lights: 1st Anniversary Website

React + Vite + JavaScript.

## Run
```
npm install
npm run dev        # local
npm run build      # production build in /dist (deploy to Vercel / Netlify)
```

## Edit everything in `src/config.js`
- `him`, `her`: names
- `wedding`: wedding date & time (the live "together for" counter and the stats use it)
- chapter titles/lines, the 12 month messages, promises, letter, signature
